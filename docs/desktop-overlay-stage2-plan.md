# CPCV Desktop 第2段階設計

## 目的

第1段階で確認した透明、最前面、カーソル透過を、授業で迷わず使える操作系へまとめる。

## v0.2で実装する範囲

- 操作用トップレベルウィンドウをCPCV管理画面1つへ統合
- 本番環境への自動接続
- staging選択を通常UIから撤去
- 授業IDと投影URLの手入力を撤去
- `/admin/{sessionId}`から授業IDを自動取得
- 既存の投影ボタンをオーバーレイ開始へ置換
- 非メインディスプレイを自動選択
- 投影先の順次切替
- 投影開始、停止、コメント、QRだけを管理画面右下へ追加
- リモートCPCVへTauri権限を付与しない

## v0.2で変更しないもの

- Worker
- D1
- 認証方式
- 学生投稿画面
- コメント保存
- AI翻訳とモデレーション
- WebSocketとRealtime
- Web版の通常投影画面

## 第2段階後半で検討する項目

### v0.2.1 実機安定化

- PowerPointスライドショー開始後の最前面再確認
- HDMI抜き差し時の再配置
- スリープ復帰
- DPIが異なる複数画面
- オーバーレイ異常終了の検出
- 管理画面終了時の確実なプロセス終了

### v0.3 通信耐性

- WebSocket失敗の検出
- HTTPSポーリングへの自動切替
- 再接続後のsequence追従
- APU Wi-Fi、テザリング、VPNでの比較試験

### 配布段階

- NSISインストーラー
- Windowsコード署名
- 自動更新
- バージョン互換性管理
- アプリコンテスト提出用の説明資料と再現ビルド手順

## 合格条件

- 起動後に接続先設定が表示されない
- ログインから投影開始まで管理画面1つで完結する
- 授業IDを入力しない
- 通常起動で本番へ接続する
- コメントがPowerPointより前に表示される
- マウスとキーボード操作はPowerPointへ届く
- CPCV本体の回帰試験がすべて成功する
