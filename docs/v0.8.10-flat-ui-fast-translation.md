# CPCV 0.8.10 平面UI・高速翻訳修正

## UI

- 角丸を全画面から除去した。
- 授業管理画面の補助panelを境界線中心へ変更した。
- 強調対象だけに直線的なshadowを残した。
- buttonはhoverとactiveでshadow位置を変えた。
- 入れ子panelへ背景。枠。shadowを重ねない。

## 翻訳

- 翻訳の主経路を汎用chat modelから`@cf/meta/m2m100-1.2b`へ変更した。
- source languageとtarget languageを専用translation inputとして直接渡す。
- primary timeoutを5秒にした。
- fallbackも5秒に制限した。従来の最大24秒直列待機を最大10秒へ短縮した。
- dedicated response。OpenAI互換response。plain textを同じvalidatorへ通す。
- Queue consumer上限を3から10へ増やした。batch内parallelismを2から5へ増やした。
- PII guard。翻訳後辞書filter。D1とRealtimeの原子的保存は維持する。

外部translation APIは追加していない。Cloudflare内の専用translation modelで必要な速度とfailure isolationを得られるためである。将来のfallback追加はprovider境界内で行う。
